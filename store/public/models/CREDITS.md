# 3D part models

switch-*, hotswap-*, stab-*: converted and simplified from the KiSwitch library
(https://github.com/kiswitch/kiswitch), dual licensed MIT / CC-BY-SA 4.0.
See LICENSE-kiswitch-MIT.txt. Rebuild with `node tools/build-models.mjs`.

Keycaps, EC11 encoder, knob and 0.91" OLED are modelled in code
(src/config/parts3d.tsx) from datasheet dimensions.
